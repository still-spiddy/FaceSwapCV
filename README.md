# FaceSwapCV 👁️

A computer vision project built with Python and OpenCV to detect and track faces in real time, with the goal of replacing a detected face with a user-selected image.

## 🚀 Features

- Real-time face detection using OpenCV.
- Face detection using Haar Cascade classifiers.
- Custom image selection for face replacement.
- Modular structure for future computer vision improvements.

> **Project status:** Initial setup and Haar Cascade integration. Face tracking and image replacement are planned next steps.

## 🛠️ Technologies Used

- **Python**
- **OpenCV 4.10.0**
- **NumPy**
- **Haar Cascade Classifier**

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/still-spiddy/FaceSwapCV.git
cd FaceSwapCV
```

### 2. Create a virtual environment

```bash
python3 -m venv venv
```

### 3. Activate the virtual environment

On Linux:

```bash
source venv/bin/activate
```

### 4. Install dependencies

```bash
python -m pip install --upgrade pip
```
```bash
pip install opencv-python==4.10.0.84 numpy
```

## ▶️ Usage

Run the main Python script:
```bash
python script.py
```

The application will run according to the functionality implemented in `script.py`.

## 🔒 Privacy and Responsible Use

Use your own face or images you have permission to use. Clearly disclose face replacements when sharing edited media, and avoid misleading or non-consensual impersonation.
